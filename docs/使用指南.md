# afan Talking Head Agent 使用指南

本项目的源码免费开放；如果你选择调用阿里云百炼、MiMo、Fish Audio 或其他云端 AI 服务，费用由对应服务商按其当前价格向你的账户收取。本项目不会提供或代付这些服务的额度。

全程大约需要 20-30 分钟配置，密钥直接在网页里填，**不用改任何文件**。配好以后每次使用只需双击一个文件。

---

## 第 1 步：安装 Python

1. 打开 https://www.python.org/downloads/ ，点黄色的 **Download Python 3.x.x**
2. 运行安装程序，**最重要的一步**：勾选底部的 **Add Python to PATH**
   （不勾后面会失败），然后点 Install Now
3. 装完后，按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入 `python --version`，
   能显示版本号就成功了

## 第 2 步：安装 FFmpeg（视频处理工具）

方式一（推荐，简单）：
1. 按 `Win + R` 输入 `cmd` 回车，粘贴下面这行并回车：
   ```
   winget install --id=Gyan.FFmpeg -e
   ```
2. 装完后**关闭黑窗口再重新打开**，输入 `ffmpeg -version` 能显示内容即成功

方式二（如果 winget 用不了）：
1. 下载 https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
2. 解压到 `C:\ffmpeg`（保证 `C:\ffmpeg\bin\ffmpeg.exe` 存在）
3. 打开软件后，点左下角「⚙ 设置」，切到 **API Key**，在 **FFmpeg 路径** 里填 `C:\ffmpeg\bin\ffmpeg.exe`，保存

> 没装 FFmpeg 也能打开软件，但混剪、字幕、导出视频用不了。

## 第 3 步：申请 AI 密钥

### 3.1 阿里云百炼（必填，改口型视频就靠它）

1. 打开 https://bailian.console.aliyun.com/ ，用支付宝/淘宝账号登录
2. 开通百炼服务（**注意地域必须是"华北2（北京）"**，不是的话切换地域）
3. 右上角头像 → **API-KEY** → 创建 API Key，复制保存
4. 在控制台找到 **业务空间**，进入详情页，复制**业务空间 ID**
   （如果没有业务空间，就新建一个）
5. 在百炼控制台的模型广场里，确认已开通 **VideoRetalk（声动人像）**

### 3.2 MiMo（必填，文案改写和配音）

1. 打开 https://platform.xiaomimimo.com/ ，注册并实名认证
2. 在控制台创建 API Key，复制保存

### 3.3 通用接口（选填，适用各种中转站/海外模型）

如果你用的不是上面这几家，而是**中转站、海外模型、自建网关**等
"OpenAI 兼容"服务，不用单独学它的填法——在设置的 **「文案改写」**
模块里选 **「自定义（OpenAI 格式）」**，
填 **接口地址 + API Key + 默认模型名** 三项即可。
填了之后，文案识别与改写的"自动"模式会优先走这个接口。

> 不确定你的服务是不是 OpenAI 兼容？大多数中转站和 DeepSeek、通义、
> 各种"套壳 API"都是。填好地址和密钥后直接试生成一次，报错的话换回默认家即可。

### 3.4 可选密钥（不用可以先跳过）

- **DeepSeek**：https://platform.deepseek.com/ （文案改写快速模式）
- **Fish Audio**：https://fish.audio/ （克隆你自己的私有音色）

## 第 4 步：在网页里填密钥（不用碰任何文件）

1. 双击 **`一键启动.bat`**，等浏览器自动打开工作台页面
2. 如果还没配过密钥，页面会**自动弹出「设置」窗口**；
   没弹出就点左下角的 **「⚙ 设置」** 按钮
3. 点 **「API Key」**，密钥按环节分好了模块，每个模块先用下拉框选服务商，
   选完就出现这家的填写框：
   - **文案提取（ASR）**：选 MiMo 或阿里云百炼
   - **文案改写**：选 MiMo / DeepSeek / 阿里云百炼，或「自定义（OpenAI 格式）」
   - **改口型（必填）**：阿里云百炼——「API Key」+「业务空间 ID」两个框
   - **声音复刻 / 配音**：选 MiMo / Fish Audio / 阿里云百炼
   - **其他**：FFmpeg 路径等，一般不用填
4. 每家标了 **必填/选填** 和 **已配置/未配置** 状态；
   同一家的 Key 全软件通用，填一次就行；
   填完点 **「保存设置」**，必填项都变"已配置"后直接开始创作，不用重启
5. 保存后到第 3 步 / 第 4 步界面顶部的「模型」下拉框里选具体模型即可

> 填了哪家，对应环节就用哪家——比如只填了百炼和 MiMo，
> 改写自动走 MiMo；再填了通用接口，改写和写稿就自动优先走它。

> ⚠️ 密钥默认只保存在你当前 Windows 用户的 `%LOCALAPPDATA%\afan Talking Head Agent` 数据目录中，不会写入 Git 仓库或安装目录。不要发到群里、不要截图。
> 别人拿到等于拿到你的钱包。

## 第 5 步：启动

双击 **`一键启动.bat`**：
- 第一次运行会自动安装依赖，需要几分钟，别关窗口
- 之后浏览器会自动打开工作台页面
- 关闭黑窗口 = 关闭软件

## 常见问题

**双击启动后提示"没有找到 Python"**
→ 第 1 步没勾选 Add Python to PATH，卸载重装 Python。

**杀毒软件 / Windows Defender 报警**
→ .bat 脚本启动本地服务，部分杀毒软件会误报，选择"允许运行"即可。
应用在你的电脑上运行。启用 ASR、配音或改口型等云端步骤时，相关素材会按你的操作发送至你已配置的 AI 服务。

**页面打开了，但生成时报"未检测到密钥"**
→ 点左下角「⚙ 设置」，切到 **API Key**，看必填项有没有"未配置"的，
把密钥粘贴进去点「保存设置」。填完直接重试，不用重启软件。

**参考视频**
→ 点击“选择本地视频”上传你有权使用的参考视频。

**端口被占用（提示 port 8000）**
→ 关掉其他正在运行的本软件窗口，再重新启动。
